# WEB102 Prework - *Sea Monster - A crowdfunding app*

  

Submitted by: **Manisha Karim**

  

**Sea Monster - A crowdfunding app** is a website for the company Sea Monster Crowdfunding. The website has the information about all the games that are funded and the ones that are waiting for funding.

Time spent: **15** hours spent in total

  

  
  

**Features**

------------

  



* Displays total contributions, total amount raised, and the number of games.


*  Filters and displays games that haven’t met their funding goals.

*  Filters and displays games that have met or exceeded their funding goals.

*  Resets the list to display all games.

* Displays game details such as name, description, backers, and an image.

* Includes dynamic content for top-funded games and additional summary statistics.

  
  

**Technologies Used**

---------------------

  

*  **HTML**: For page structure and layout.

*  **CSS**: For styling and visual appeal.

*  **JavaScript**: For dynamic content, DOM manipulation, and interactivity.
